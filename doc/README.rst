==============================
dgcode_projects documentation
==============================

To build and view the documentation locally, type `make html` in this doc/
directory (in the dgcode conda environment, with the packages of
https://github.com/mctools/simplebuild-dgcode/blob/main/.github/resources/conda-setup_extra_for_docs.yml
added), and direct your browser at doc/build/html/index.html.
